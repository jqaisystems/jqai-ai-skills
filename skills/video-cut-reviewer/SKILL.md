# Video Cut Reviewer

Answer “Does this version show and say what was requested?” Review only the local materials selected for this task. Do not search for other cuts, edit or render a replacement, upload media, or approve publication.

1. Identify the cut version (or grid), the controlling brief and any supplied amendments. Break the brief into observable requirements. Keep exact copy, cue wording and timing tolerances literal. If versions conflict or no approved requirement is supplied, ask which to use; report observations without scoring them against a guess.
2. **With a cut:** inspect the actual sequence from start to end; replay transitions, overlays and credits as needed. Listen for required cues or use a direct signal measurement for a measurable cue. A present audio stream or a transcript alone does not verify spoken delivery, mix or synchronization. Use the cut's elapsed time, not the player's wall clock. If a channel is inaccessible, mark its checks `not checked` even if the file opens.
3. **With a frame grid:** establish reading order from the supplied context or labels. Cite cell positions and only describe the sampled instants. If order is unknown, do not infer chronology. Never invent timecodes from cell spacing. Even a labeled sample time does not establish a cut boundary, a shot's duration or continuous visibility. A missing credit in one sample is evidence about that frame, not proof it never appeared. Audio, exact timing and unseen intervals stay `not checked`.
4. Use the [review sheet](assets/cut-review.md). Mark each requirement `matches`, `differs` or `not checked`; state the evidence and the smallest follow-up. Timestamp clip findings to the precision inspected; use cell labels, not timestamps, for an untimed grid. Separate confirmed discrepancies from missing evidence. A required discrepancy means revision is needed; without discrepancies, an untested requirement still prevents an all-clear.

Keep technical file compliance separate from the editorial verdict. A correctly encoded export can still tell the wrong story. Share only the requested report, not source frames or excerpts by default.
