# Fictional proof: Example Studio

**Logo.** The approved mark is a white ring. The brief requests a 32 × 32 transparent reverse PNG on dark charcoal and a vector-only master. The supplied PNG differs from the intended dark background, but disappears on white. A white-background variant promised in the brief is still missing. Record these as three different results: measured dark-background check passed, white-background use blocked, required variant missing. Do not promise print readiness. An SVG containing only an image wrapper fails the vector-only requirement.

**Screenshot.** A guide contains a fictional board screenshot at figure-1. In the first draft the image still contains a fictional private note; the HTML puts a solid rectangle over it. The page looks covered, but its shipped image is recoverable: BLOCK. Recreate the screenshot with only synthetic, shareable labels and replace the underlying file. Inspect the new image, its final rendered placement and all downloadable dependencies. In the fixture a simulated clear review matches only that exact combination. Moving the screenshot, editing the guide or changing the image requires fresh review. No fixture is evidence of actual human approval.
