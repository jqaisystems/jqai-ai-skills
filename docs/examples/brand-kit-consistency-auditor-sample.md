# Example Studio: visual identity handoff

## Selected fictional evidence

- Approved guide G3: charcoal mark K1 on pale surfaces, white mark K2 on dark surfaces. Body type: Sample Sans. Accent: Ember, #B84531.
- Final inventory I3 (complete for logo exports only): K1 = charcoal.svg, K2 = white.svg. No files or permission records supplied for inspection.
- Handoff H3: pale → K1; dark → K1; body type → Sample Sans; include its font file for recipients; accent → Ember, #B84531.
