## Reproducible checks

```text
python tools/validate_skills.py
python tools/check_markdown_links.py
python tools/check_public_safety.py
python -X utf8 -B -m unittest discover -s tests -p "test_*.py" -v
```

On Windows, run the mocked collector test:

```powershell
pwsh -NoProfile -File tests/test_windows_collector.ps1
```

Python tests need Pillow. A synthetic real-video case needs ffmpeg and ffprobe; without them it is skipped, not reported as verified video coverage. Runtime helpers never install dependencies. The collector test substitutes every adapter before invoking collection and never queries installed software.

The official skill validator also needs PyYAML. Keep validation dependencies isolated from runtime installations. The Windows junction test needs PowerShell 7; the native-symlink case can skip on hosts without symlink creation rights, while deterministic reparse rejection remains tested. The existing Windows CI job separately executes the mocked collector in Windows PowerShell 5.1.

## Evidence and limits

- Media tests cover inclusive limits, display orientation, animation, malformed input, missing dependencies, timeouts, unknown checks, local-path guards, JSON, and unchanged sources.
- Reconciliation tests cover values and types, duplicates, incomplete/stale coverage, receipt conflicts, orphan history, and unchanged inputs. No live automation is contacted.
- Windows tests cover grouping, partial coverage, missing versions/publishers, Unicode, formula-safe CSV, and overwrite refusal. Registration is not application execution proof.
- Metadata tests cover PNG/JPEG/WebP/GIF, selective XMP, supported Photoshop text, malformed and unsupported structures, idempotence, encoded data, and rendering preservation.
- An independent fictional article exercise checks conflicting dates, unavailable dates, unsupported claims, credits, usage holds, separate article dates, and asset decisions.
- Independent forward tests led to fixes for mixed failure/unknown reporting, uncertainty precedence, unknown-publisher grouping, and metadata preservation. They supplement the committed deterministic tests, not substitute for them.

All five changed skills receive official structural validation and separate no-baseline safety review before handoff. Repository checks cover all 46 skills. Public packaging excludes inventories, snapshots, actual media, private helper folders, personal configuration, and interpreter caches.

Release publication requires explicit human approval and passing GitHub Actions on the release commit before tagging. The release page records that remote result; the dated local checks above do not establish it.
