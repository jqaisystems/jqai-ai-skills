# v0.16.0: Release and brand consistency checks

Release scope: 51 skills. The new [brand-kit-consistency-auditor](../../skills/brand-kit-consistency-auditor/SKILL.md) compares approved visual rules with the inventory and handoff sheet. It distinguishes a wrong reference from a missing export and does not infer redistribution permission.

[Release announcement writer](../../skills/release-announcement-writer/SKILL.md) now checks selected documents against release evidence as well as drafting copy. The optional offline helper compares normalized claims without fetching links, changing documents or publishing.

See the [brand handoff example](../examples/brand-kit-consistency-auditor-sample.md) and the [post-release review](../examples/release-consistency-sample.md). This scope note is not evidence that a tag or release exists.
