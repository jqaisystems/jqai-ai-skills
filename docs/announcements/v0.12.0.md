# v0.12.0: Local Verification and Recovery

Draft release announcement. Not published; human approval and remote CI remain pending.

This candidate expands the library from 43 skills on main to 46 with three independently usable utilities:

- **media-spec-checker** measures local images and videos against supplied JSON rules, keeping unavailable measurements visibly unverified.
- **automation-state-reconciler** compares offline snapshots and delivery receipts and prepares a repair plan without connecting to or changing production systems.
- **windows-reinstall-planner** organizes software registration metadata into private inventory, checklist, and collection-coverage artifacts without installing or removing software.

Two existing skills improve:

- **remove-ai-image-metadata** adds selective XMP and supported Photoshop handling, preserving unrelated metadata and encoded content while refusing unsupported or malformed cases.
- **research-to-article** separates source, video, publication, and update dates and makes embed credits, permissions checks, and visual-asset decisions explicit.

The corrected catalog includes four additions already present on main since August: ai-image-run-pacing, local-app-public-demo, thumbnail-legibility-check, and thumbnail-set-designer. This candidate does not alter their implementations.

## Safety and verification

New examples are fictional. Automation stays offline. Windows collection tests are mocked. Media tests use disposable synthetic inputs. Generated operational inventories, snapshots, and reports stay private.

See the [verification scope](../examples/v0.12.0-verification.md), [catalog](../catalog.md), and [quality matrix](../skill-quality-matrix.md). Local test and review evidence does not imply publication or passing remote CI.
