# v0.9.1

JQ AI Skills adds `remove-ai-image-metadata`, a format-aware image utility with an inspect-first workflow, verified copy output, and explicit responsible-use boundaries. The release grows the library from 32 to 33 skills.

## What's changed

- Added the complete `remove-ai-image-metadata` skill folder with agent metadata and a standard-library Python helper.
- Added byte-preserving cleanup for explicit AI provenance metadata in PNG, JPEG, WebP, and GIF containers.
- Added post-write reparsing and encoded-payload hash checks before a changed file can report `PASS`.
- Added copy-first defaults, optional in-place backups, unsupported-format stop conditions, and warnings around EXIF orientation and other co-located fields.
- Added a catalog entry, quality-matrix row, quick-reference prompt, and public-safe sample output.
- Strengthened the release checklist and pull-request template with behavior review, candidate scanning, named-file diff review, and explicit approval gates.

## Safety

- The helper makes no network calls and reads only user-selected files.
- Inspection is the default; writing requires an output folder or explicit in-place mode.
- Use is limited to files the user owns or is authorized to modify.
- Removing explicit metadata does not change how an image was created and must not be used to misrepresent provenance or bypass disclosure requirements.
- The skill never claims a cleaned image is undetectable or no longer AI-generated.
