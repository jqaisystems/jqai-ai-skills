# v0.14.0 candidate: Safe Publishing Handoffs

Status: prepared for review, not published. Remote CI and publication approval remain pending.

The candidate expands the library from 47 to 49 skills:

- static-site-handoff prepares and verifies local upload packages from completed static builds, preserving an explicit user-confirmed baseline.
- article-cover-adapter guides adaptations of approved artwork without losing exact wording, branding, important artwork or visible credits.
- social-campaign-proof-tracker gains exact-package fingerprints, approval-record comparison and conservative receipt-state auditing.
- remove-ai-image-metadata gains a separate read-only verifier for supported selective cleanup, encoded content, colour, orientation, decoded frames and animation.

The new helpers do not upload, schedule, publish, install dependencies or authenticate human consent. Existing metadata-cleaner commands and inspect-only defaults remain unchanged. Unsupported metadata structures are still refused.

Local verification uses synthetic fixtures, official skill validation, repository checks, safety review and disposable installation targets. Real deployment packages, approval records, images, accounts, private reports and validation environments are excluded.

The local regression run completed 99 tests: 96 passed and three native-symlink tests were skipped because this Windows account cannot create symlinks. Deterministic reparse checks, real Windows directory-junction checks, and synthetic video coverage passed. The new handoff suite accounts for 33 of these tests. Remote Linux/Windows CI has not run for this unpublished candidate.

Inspect the [static handoff sample](../examples/static-site-handoff-sample.md), [cover adaptation sample](../examples/article-cover-adapter-sample.md), [campaign evidence sample](../examples/social-campaign-proof-tracker-sample.md), and [metadata verification sample](../examples/remove-ai-image-metadata-sample.md).

Publication requires a separately reviewed exact file manifest, human approval, and passing CI on the approved commit.
