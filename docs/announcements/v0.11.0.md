# v0.11.0: Evidence-Based Writing

JQ AI Skills adds three standalone workflows for checking public claims, turning verified research into finished articles, and drafting professional profile copy from approved evidence. The release grows the library from 36 to 39 skills.

## Added

- `verify-public-claims`: classify material claims as supported, qualified, inference, unsupported, or stale, then produce defensible rewrites.
- `research-to-article`: create a claim map, metadata, finished article, Link Map, and verification report without publishing.
- `write-evidence-backed-profile`: produce bios, applications, portfolio introductions, proposal introductions, and cover notes without inventing experience or results.

## Verification

- All 39 public skill folders pass repository validation.
- All three new skills pass official structure validation and independent synthetic forward tests.
- Claim verification covers supported, qualified, inference, unsupported, and stale statements.
- The sanitized candidate and each new public skill pass public-safety scanning with no findings.
- Repository links, named-file staging, staged diffs, and GitHub Actions are checked before tagging.

## Safety

- All examples use fictional identities, source excerpts, and `example.com` links.
- The skills contain no personal source registry, user-specific website, local path, client material, account data, raw prompt, or memory content.
- The skills do not publish, submit forms, send messages, modify websites, or update public profiles.
- Current or high-stakes claims require authoritative evidence and appropriate human review.
