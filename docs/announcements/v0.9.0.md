# v0.9.0

JQ AI Skills adds nine new skills and two new categories. Client Work covers the freelance engagement end to end: scaffold the client folder, run discovery, write the proposal, and catch the follow-ups you forgot. Agent Workflow makes the AI-assisted work itself repeatable: turn workflows into skills, hand sessions off cleanly, and serve one skill set to both Claude Code and Codex.

This is the largest release since v0.8.0 and grows the library from 23 to 32 skills.

## What's changed

### Added: Client Work

- `client-workspace-scaffolder`: scaffolds a complete client project folder from a structure template you define once. Never overwrites existing work.
- `discovery-brief`: runs a structured discovery interview across seven areas and writes a completed brief plus a strategy starter. Never fabricates unanswered questions.
- `proposal-writer`: drafts a client proposal from your own service tiers, saved once in an ask-once pricing config. Drafts only.

### Added: Growth and outreach

- `follow-up-radar`: scans a folder of outreach markdown for overdue follow-ups, reports oldest first, and drafts the messages. Report-first; a human sends everything.

### Added: Agent Workflow

- `skill-builder`: authors a new skill correctly, from trigger-matching description to storage tier, cross-workspace linking, and registration for agents that do not auto-load skills.
- `session-handoff`: freezes session state into a START_HERE.md with decisions, next steps, and gotchas, readable with zero context.
- `agents-md-writer`: generates the AGENTS.md plus CLAUDE.md contract that lets one skill folder serve both Claude Code and Codex.
- `ops-status-report`: compiles a configurable workspace status snapshot ending in an Attention Needed section. Read-only except the report file.

### Added: Demo and presentation

- `screen-recorder`: records a drag-selected region of the Windows desktop to a clean, seekable MP4 with FFmpeg. Previously available only on the website, now a repo skill.

### Docs

- README: added Client Work and Agent Workflow categories, nine prompt examples, and chooser rows.
- `docs/catalog.md`: added At A Glance rows, nine detail sections, and two new bundles: Freelance Client Flow and Agent Workflow Setup.
- `docs/skill-quality-matrix.md`: added maturity, proof, safety, and install notes for all nine skills.
- `CHANGELOG.md`: added the v0.9.0 entry.

## Safety

- Every business skill loads personal data (prices, templates, folders) from an ask-once config file. Nothing personal is hardcoded.
- `proposal-writer`, `follow-up-radar`, and `discovery-brief` are drafts-only or report-first. Nothing sends, posts, or fabricates.
- `ops-status-report` is read-only except for the report file it writes.
- `screen-recorder` records whatever is on screen; the skill reminds users to clear sensitive windows first.
