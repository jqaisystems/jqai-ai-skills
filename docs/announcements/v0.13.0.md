# v0.13.0: Safer Skills and Recovery

Release date: 2026-10-14. Publication requires passing CI on the exact release commit.

This release expands the library from 46 to 47 skills:

- **backup-readiness-auditor** checks supplied backup evidence for coverage, integrity, freshness, capacity, and recovery-test gaps. It never reads backup contents or authorizes source retirement.
- **github-safe-publisher** withholds matching text from reports, protects baseline access, scans baseline contents, and documents exact-file approval and exact-commit CI gates.
- **skill-builder** and **agents-md-writer** now distinguish native discovery from project routing and preserve shared/private installations.
- Both installers share a Python 3.11+ safety core with dry-run preflight, managed-copy receipts, explicit upgrade approval, and retained backups. Unmanaged folders, local changes, and links are protected.

Tests use fictional evidence and disposable local files. No real backup, application inventory, access file, or installed private skill is used as a fixture.

Local validation covered all 47 skills, Markdown links, the full 66-test regression suite (64 passed and two permission-dependent skips), and 11 independent synthetic checks. Safety scans found zero blocking findings; all non-blocking findings were reviewed.

See [backup evidence proof](https://github.com/jqaisystems/jqai-ai-skills/blob/v0.13.0/docs/examples/backup-readiness-auditor-sample.md), [maintenance proof](https://github.com/jqaisystems/jqai-ai-skills/blob/v0.13.0/docs/examples/safer-skills-recovery-sample.md), and [installation behavior](https://github.com/jqaisystems/jqai-ai-skills/blob/v0.13.0/docs/guides/safe-installation.md). The GitHub release records the exact commit and passing CI run.
