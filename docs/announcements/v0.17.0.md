# v0.17.0: Responsive website verification

The library remains at 51 skills. [Website change verifier](../../skills/website-change-verifier/SKILL.md) adds a reusable, per-page interaction results table and clearer rules for reporting incomplete coverage. A successful HTTP request does not prove that a button works. A local browser result does not establish live behavior.

The [fictional example](../examples/responsive-website-verification.md) shows a narrow-screen failure and the retest after fixing the fixture. The route checker CLI and its dependencies are unchanged. This scope note is not a publication record.
